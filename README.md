# Teenancial

Teenancial adalah aplikasi yang dirancang khusus untuk membantu remaja mencatat dan mengelola keuangan harian secara mandiri dan disiplin. Aplikasi ini memfasilitasi pencatatan empat aktivitas keuangan (pemasukan, pengeluaran, peminjaman, dan transfer), manajemen dompet digital/tunai, serta penetapan target tabungan (savings goal) lengkap dengan grafik tren saldo dan pengingat otomatis. Dilengkapi juga dengan Companion Chatbot berbasis AI untuk edukasi literasi keuangan serta penyimpanan yang aman menggunakan ekosistem Firebase.
