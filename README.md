# Teenancial

Teenancial adalah aplikasi yang dirancang khusus untuk membantu remaja mencatat dan mengelola keuangan harian secara mandiri dan disiplin. Aplikasi ini memfasilitasi pencatatan aktivitas keuangan (pemasukan, pengeluaran), manajemen dompet digital/tunai, penetapan target tabungan (savings goal) lengkap dengan grafik tren saldo secara dinamis, serta ruang pembelajaran pengelolaan keuangan.

## Prasyarat Lingkungan (Setup)

Untuk menjalankan proyek ini, pastikan Anda telah menginstal dan mengkonfigurasi lingkungan berikut:
- **Flutter SDK:** Versi `3.47.2` atau yang lebih baru.
- **Dart SDK:** Versi `3.13.2` atau yang kompatibel dengan Flutter 3.47.2.
- **IDE:** Android Studio dengan Emulator atau perangkat fisik (Android/iOS).

## Cara Menjalankan Aplikasi (Setup & Run)

1. Clone repositori atau ekstrak file ZIP proyek ini.
2. Buka terminal pada folder proyek `Teenancial`.
3. Jalankan perintah untuk mengunduh semua dependensi:
   ```bash
   flutter pub get
   ```
4. Jalankan aplikasi di emulator atau perangkat fisik (Android/iOS):
   ```bash
   flutter run
   ```
   *(Pastikan tidak ada folder `build` atau `.dart_tool` yang tertinggal saat mengekstrak zip untuk menghindari konflik cache).*
